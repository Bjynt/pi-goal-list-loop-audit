# Goal

**Status**: active
**Policy**: list
**Auto-continue**: on

## Objective

> Add the model-switch ledger (policy compliance). Detect `provider.model` changes on each turn boundary and append a `model_switch` ledger entry. Add a `forbiddenModels` setting (default forbids `gpt-5.5`/`sonnet`/`opus`) that emits `forbidden_model_switch` and (configurable) blocks the call. Add a `/glla switchlog` command.

## Verification contract

- (a) `extensions/goal-loop-core.ts` exports a `modelSwitch(from, to, reason, at)` helper and a turn-boundary hook writes the entry
- (b) the `forbiddenModels` setting blocks forbidden models and emits the violation event
- (c) `/glla switchlog` renders the last N entries
- (d) a test in `tests/model-switch.test.ts` pins each
- (e) full suite green and `npx tsc --noEmit` clean
