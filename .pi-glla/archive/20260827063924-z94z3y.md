## Completion summary

Fixed the issue where the agent did not auto-recover from tool call format errors (e.g., "The model produced output that does not match the expected peg-native format").

The root cause was that the `classifyMainModelFailure` function in `extensions/main-model-recovery.ts` did not recognize tool call parsing/validation errors as recoverable. These errors (like "peg-native format" errors) occur when the model emits malformed tool calls that fail TypeBox schema validation. Previously, these were classified as "unknown" which meant they didn't trigger the recovery machinery.

The fix adds a pattern match for tool call format errors (peg-native, tool call format/parse, invalid tool call, malformed tool) and classifies them as "transient" recoverable failures, so the main-model recovery machinery kicks in and walks the fallback chain to a working model.
